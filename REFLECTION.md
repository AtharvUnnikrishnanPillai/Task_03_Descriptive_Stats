# From one dataset to three

Task 2 had reliable reducers but assumed every input contained page_id and ad_id. That assumption breaks immediately on Facebook posts (Facebook_Id) and Twitter/X (no explicit account ID). The reusable part turned out to be the statistical calculation, not the choice of group. In Task 3 the command line supplies grouping columns and the runner documents the choices for each file. A fourth CSV can be summarized without an election-specific branch. A user still needs to choose a meaningful unit of analysis.

Loading strings before inference preserves leading zeros and permits consistent missing-value rules. Identifier naming differs between snake case, spaces and camel case. A second example is that a binary label can be written as 1 in one file and 1.0 in another. Treating both as numeric makes their positive rates comparable; counting literal strings would not. The combined Facebook header is retained rather than guessing at a repair. For an unrelated survey, local missing codes or a numeric-looking geographic code may still need an explicit schema rule. Encoding is configurable rather than guessed.

Pure Python makes the variance formula, group dictionaries, and ties inspectable. Pandas makes it easier to inspect a column and cross-check descriptive statistics. Polars uses explicit expressions and typed results; its grouping is useful even without a Pandas-style index. This implementation still performs Python work per group, so the library names alone do not establish a speed ranking. A controlled benchmark would require repeated runs, comparable hardware and separate accounting for file I/O.

The most useful comparison was the proportion of scored records labeled as calls to action. The field is present across all three files, but a missing label cannot be counted as a negative one. In contrast, ad impressions and post likes describe different events even when both are integers. Consistency of three software outputs tests computation, not whether a comparison makes sense.

AI assistance helped adapt the Task 2 scripts. A concrete review step was to examine headers before choosing grouping keys: using source as if it identified a Twitter author would have compared posting applications as though they were people. Known-answer tests check sample variance, tied modes, missing keys, repeated pairs, and singleton groups. Agreement across engines complements those tests; it cannot independently verify shared cleaning rules or the original classifier.
